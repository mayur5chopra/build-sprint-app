## Seven-day AI cost estimate

Model: `sarvam-105b-conversations`.

- 50 user messages per day for 7 days = 350 model replies.
- Estimate per reply: 500 input tokens and 80 output tokens. The app limits conversation context to the latest 12 messages.
- Weekly input: 175,000 tokens × ₹15 per 1M = ₹2.625.
- Weekly output: 28,000 tokens × ₹60 per 1M = ₹1.68.
- Estimated total: **₹4.305, or about ₹4.31 per user per week**.
- Practical cost will vary as conversation context grows.

This is the Sarvam model cost only. It does not include any Convex plan cost.

Official pricing source: https://docs.sarvam.ai/api/getting-started/pricing
