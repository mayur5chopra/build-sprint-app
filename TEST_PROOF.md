## Browser test

1. Signed in with a disposable test account.
2. Confirmed the 18+ gate and the clear AI disclosure.
3. Started session 1 and sent `kal meri presentation hai`.
4. Started session 2.

6. Saw a natural Hinglish reply generated by Sarvam and the memory confirmation appear.

8. Kamini replied `Main ek female AI companion hoon...`.

This confirms the live model identifies as a female AI companion and uses feminine Hinglish grammar.

## Personality test

1. Sent `Aaj office mein meri presentation kharab ho gayi. Boss ne sabke saamne bola ki main prepared nahi tha.`
2. Kamini responded to the specific embarrassment: `Public mein boss aisa bole toh sach mein bahut awkward feel hota hai.`

This confirms the live model notices specific details, follows the conversation, and changes tone without dropping the female Hinglish persona.

## AI connection status

Live replies use Sarvam's `sarvam-105b-conversations` model. The `SARVAM_API_KEY` is stored in the Convex development and production environments, not in the repository. A real Hinglish reply was verified in Chrome at `https://outstanding-zebra-774.convex.site`.

## Seven-day AI cost estimate

Model: `sarvam-105b-conversations`.

- 50 user messages per day for 7 days = 350 model replies.
- Estimate per reply: 500 input tokens and 80 output tokens. The app limits conversation context to the latest 12 messages.
- Weekly input: 175,000 tokens × ₹15 per 1M = ₹2.625.
- Weekly output: 28,000 tokens × ₹60 per 1M = ₹1.68.
- Estimated total: **₹4.305, or about ₹4.31 per user per week**.
- Practical cost will vary as conversation context grows.

This is the Sarvam model cost only. It does not include any Convex plan cost.

Official pricing source: https://docs.sarvam.ai/api/getting-started/pricing
